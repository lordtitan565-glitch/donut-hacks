# Donut Hacks (v0.3.0) - Minecraft 1.21.11, Fabric

Open the menu in game with RIGHT SHIFT. Click a module to toggle it; click a small setting button to cycle its value.

## Modules in v0.3.0
- Combat: Aim Assist (hold attack)
- Movement: Toggle Sprint, Freecam (WASD + mouse to fly, Space up, Left Shift down; your real player stays still; optional line and box showing where your body is)
- Visual: Glow ESP (outlines players/items/mobs), Box ESP (boxes around players, items, mobs, storage), Tracers (lines to players/storage)
- World: Storage Finder (chests, barrels, shulkers in chat), Base Finder (flags chunks with lots of storage/furnaces/beds)

Most modules have colour and on/off settings you can cycle in the menu.

Box ESP and Tracers are drawn on the screen (2D), so they show through walls. They can drift a little while sprinting because the game widens your FOV.

## Get the .jar (no coding, free)
1. Make a free account at github.com and sign in.
2. Click + (top right) > New repository. Name it donut-hacks. Create it.
3. Unzip this ZIP. On the new repo page click "uploading an existing file".
4. Drag EVERYTHING from the unzipped folder in (including the .github folder). Click Commit changes.
5. Open the Actions tab. Wait for "Build Donut Hacks" to finish (green check, about 3-5 min).
6. Click the finished run, scroll to Artifacts, download donut-hacks-jar. Unzip it to get the .jar.
7. Put the .jar in your .minecraft/mods folder with Fabric Loader and Fabric API for 1.21.11 installed.

If the run shows a red X, open it, copy the error text, and send it to me.
